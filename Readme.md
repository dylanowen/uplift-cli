# Uplift CLI

### Sit

```bash
uplift sit
```

```bash
uplift sit save
```

### Stand

```bash
uplift stand
```

```bash
uplift stand save
```

### Query

Get the current height

```bash
uplift query
```

### Listen

Continuously get the height

```bash
uplift listen
```
